# TCP / FIX 本地工作台

用户授权完成全部实现，常规疑问自行裁决，后续用户验收。目标目录为本仓库，参考 Apifox 的左侧服务树、右侧请求标签、报文与前后置脚本、底部响应区域。技术为 Go + Vue，DDD 分层，Windows 桌面优先。

## 必须交付
1. TCP 长连接、持续接收、主动推送、串行发送、手动断开与清晰状态。
2. 前后置 JavaScript、会话变量、可见日志、可启动停止的定时任务、当前连接发送 API。
3. 请求处理、返回处理、接收完成判断三类函数；分帧必须正确处理粘包、分包、尾部残包。
4. 独立 FIX 入口，导入 QuickFIX XML 字典；支持 message、field、枚举、component、嵌套 group、required；运行时生成 Vue 表单。
5. FIX 自动头尾、UTC 时间、序号、校验和、登录、心跳、TestRequest 应答、退出；原始编辑供异常测试。
6. 服务、请求、函数、字典、用例本地保存，导入导出；原始与处理后数据、HEX/Base64、历史与脚本日志。
7. AGENTS.md、README.md、架构、脚本 API、验收文档与可运行 Windows 构建。
8. XML 导入先只读预览并选择接口，支持名称/类型搜索、多选、全选当前结果及清空，默认不全选，至少选一项才确认。确认后创建同名 FIX 服务及选中的命名模板，完整字典保留用于表单/解析。取消不落库；新建 FIX 服务只选择协议版本后直接保存，不需要 XML 或模板选择；已有服务补全按选择添加，不覆盖已保存用例。新建 FIX 请求可选字典类型。左侧服务与消息提供确认删除，删除服务同时清理连接、任务与所属消息，结果重启保持。
9. TCP 服务接收规则直接绑定接收完成判断类自定义函数，显示函数名和绑定提示；支持从服务设置往返函数管理并保留草稿，保存、刷新后保持绑定，重连后执行真实拆包。

10. FIX 字典、预览和会话支持 FIX 4.0～4.4；BeginString 跟随手选内置版本，或从导入 XML 的 type/major/minor 自动识别版本，管理消息与重发同版本，拒绝对端版本不匹配。旧字段类型、时间精度、自动登录字段按字典适配。多版本服务并存，界面显示版本。FIX5.x/FIXT 暂不实现并明确拒绝，TCP 保持通用。

## 验收

侧栏搜索需过滤到具体消息，匹配服务名、消息名与消息类型，忽略大小写及首尾空格；自动展开匹配服务，提供无结果提示和清除入口。搜索只改变展示，清除或搜索中保存后重启仍保留完整消息。
真实 loopback TCP 验证同连接持续收发、主动推送、分包粘包、定时任务清理；FIX44.xml 导入包含 181 消息/26 组件/1262 字段并可生成业务表单；模拟 FIX 对端验证登录/心跳/序号/校验；桌面和浏览器共用应用用例，前端完成类型检查、生产构建与交互检查。

## 边界
单用户本地工具，不建设账户/云同步系统。FIX XML 不包含业务条件、中文标签或响应配对，允许脚本补充。保留手动原始报文模式。浏览器适配仅监听 loopback，并校验请求来源。

## 本轮验收补充

协议库为空时可新建 FIX4.2 服务并直接保存，不触发文件选择器、XML导入或接口选择，协议库仍为空。保存后可从内置标准添加 Logon/Heartbeat，预览及实际登录/TestRequest应答使用FIX4.2，重启保持。旧自定义字典服务保留。XML 文件名与根节点版本不同时，以根节点为准。窗口页脚显示20261030.1并提供同名日期包。

## 验收补充：请求独立调试
收发事件按请求隔离；自动心跳/无法归属的推送进入会话记录。FIX按业务标识及引用序号关联，普通TCP默认一帧一应答的FIFO。定义、文档、调试共用请求结构；可增删字段和重复组，标准/XML原件保持。字段单列，每行一个字段，组记录展开编辑。调试报文提供较大的可编辑区，管理模式重算会话头、时间、长度和校验和，原始模式保持字节。解码保留全部字段，未知项明确标识。

## Phase11验收补充
FIX自动心跳状态、间隔和最近发送时间在定时任务页可见，未登录明确等待登录。普通TCP/手写FIX支持启动当前请求周期发送、停止及断开清理，不依赖后置脚本。字段表单下仅单行预览，原始报文开关带入当前生成值供编辑，保留手工草稿，缺少必填时提示而不打开空编辑器。

调试字段必填优先：每个作用域内必填字段/组件/组稳定排在可选项之前，不修改定义数据及线缆编码顺序。
